# Sesion 2026-05-08 01

## Objetivo

Agregar "Demostracion de competencias" como nuevo tipo de documento dentro de SCRIBE, sin crear un hijo nuevo de NUCLEO ni romper el flujo actual de monografia/tesis.

## Cambios realizados

- Se agrego el tipo predefinido `tipo-demostracion-competencias` en `/api/admin/project-types`.
- Se sembraron 6 fases editables desde Admin > Tipos de Proyecto:
  - Materia, reto y competencias
  - Analisis de la problematica
  - Propuesta de solucion
  - Evidencias, tablas y anexos
  - Defensa y demostracion competencial
  - Documento final presentable
- Las fases incluyen prompts base anti-invento: deben usar materia, reto, competencias, problematica y evidencias entregadas por el estudiante.
- Se hizo visible la seleccion de tipo de documento en `/projects/new`.
- Se agrego en `/dashboard` una seccion visible de servicios disponibles con acceso directo a "Demostracion de competencias".
- El enlace `/projects/new?tipo=tipo-demostracion-competencias` preselecciona ese tipo de documento.
- Si el estudiante elige "Demostracion de competencias", el flujo pide:
  - Materia
  - Reto
  - Competencia(s)
  - Problematica
  - Informacion detallada, tablas o evidencias disponibles
- El proyecto se crea como oferta de SCRIBE usando `mono-001`, para reutilizar workspace, IA por servicio, fases dinamicas, carga de documentos y exportacion.
